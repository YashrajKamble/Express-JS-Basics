## Express JS Basics & Blog Demo

This repository contains **two small Express-based Node.js applications**:

- **Root app (`expressjsbasics`)**: minimal Express server exposing basic routes and static assets.
- **Blog app (`EXPRESSBLOG`)**: simple blog built with **Express** and **Express Handlebars**, rendering posts from an in-memory data source.

The goal of this project is to demonstrate **fundamental Express.js concepts**: routing, middleware, serving static files, and server-side rendering with Handlebars.

---

## 1. Project Structure

- **Root project (basic Express demo)**
  - `package.json` – metadata and dependencies (`express`)
  - `index.js` – main Express server (basic routes, static file serving)
  - `public/` – static assets served by the root app (if present)
  - `index.html` – example static HTML file (optional/demo)
  - `package-lock.json` – lockfile auto-generated by npm
  - `.gitignore` – Git ignore rules

- **`EXPRESSBLOG/` (blog application)**
  - `package.json` – metadata and dependencies (`express-handlebars`, `nodemon` dev dependency)
  - `index.js` – Express app entry point
  - `routes/`
    - `blog.js` – blog routes (`/`, `/blog`, `/blogpost/:slug`)
  - `data/`
    - `blogs.js` – in-memory list of blog posts (`title`, `content`, `slug`)
  - `views/`
    - `layouts/main.handlebars` – base layout (Bootstrap navbar, shared HTML structure)
    - `home.handlebars` – home page template
    - `blogHome.handlebars` – blog listing page
    - `blogPage.handlebars` – blog article detail page
    - `*.html` – legacy/demo HTML templates (not used by Handlebars)
  - `package-lock.json` – lockfile auto-generated by npm

## 3. Installation

From the project root (`e:\EXPRESS JS` or repository root):

```bash
# Install dependencies for the root Express basics app
npm install
```

The `EXPRESSBLOG` app has its own `package.json`. Install its dependencies separately:

```bash
cd EXPRESSBLOG
npm install
```

You only need to run `npm install` once per app (unless you change dependencies).

## 4. Running the Root Express Basics App

### 4.1. Start the server

From the project root:

```bash
node index.js
```

By default, the app listens on **port 3000**:

- **Base URL**: `http://localhost:3000`

### 4.2. Available routes

- **`GET /hello/:name`**
  - Responds with plain text: `Hello World! <name>`.
  - Example: `http://localhost:3000/hello/John` → `Hello World! John`

- **`GET /about`**
  - Responds with JSON:
    ```json
    { "course": "expressjs" }
    ```

### 4.3. Static files

- Static assets are served from the `public/` directory at the project root:
  - `app.use(express.static(path.join(__dirname, "public")))`
  - Any file under `public/` becomes accessible via `http://localhost:3000/<file-name>`

## 5. Running the Blog App (`EXPRESSBLOG`)

### 5.1. Start the server

From the `EXPRESSBLOG` directory:

```bash
cd EXPRESSBLOG

# Basic start (uses Node)
node index.js
```

If you want automatic reloads during development and have `nodemon` installed globally or via `npx`, you can use:

```bash
npx nodemon index.js
```

The blog app also listens on **port 3000** by default:

- **Base URL**: `http://localhost:3000`

> **Note**: Do not run the root app and the blog app on port 3000 at the same time on the same machine. Run one at a time, or change the port in one of the apps.

### 5.2. Handlebars view engine

The blog app configures Handlebars as its view engine:

- `app.engine('handlebars', engine());`
- `app.set('view engine', 'handlebars');`

All views under `views/` are rendered into `layouts/main.handlebars` via the `{{{body}}}` placeholder.

### 5.3. Static files

- Static assets (CSS, JS, images) for the blog app are expected under a `static/` directory:
  - `app.use(express.static(path.join(__dirname, "static")))`

If you add CSS/JS for the blog, place them under `EXPRESSBLOG/static/`.

### 5.4. Routes

Defined in `EXPRESSBLOG/routes/blog.js` and mounted at the root path (`/`):

- **`GET /`**
  - Renders the `home` view (`views/home.handlebars`).

- **`GET /blog`**
  - Renders the `blogHome` view (`views/blogHome.handlebars`).
  - Displays a list of blog posts, each linking to its detail page.

- **`GET /blogpost/:slug`**
  - Looks up a post by its `slug` in `data/blogs.js`.
  - Renders `blogPage` with the post `title` and `content`.
  - Example: `http://localhost:3000/blogpost/python-learning`

## 6. Blog Data Model (`blogs.js`)

The blog posts are stored in memory in `EXPRESSBLOG/data/blogs.js` as an array:

- **Fields per post**:
  - `title` – human-readable post title (e.g., `"how to get start with react"`)
  - `content` – post body/content (demo strings)
  - `slug` – URL-friendly identifier used in routes (e.g., `"react-learning"`)

To **add a new post**:

1. Open `EXPRESSBLOG/data/blogs.js`.
2. Append a new object to the `blogs` array with `title`, `content`, and `slug`.
3. Visit `/blog` to see the new post listed.

No database is used here; data is not persisted across deployments and is purely in-code for teaching purposes.

## 7. Development Notes & Common Tasks

- **Change server port**
  - In either `index.js`, modify:
    - `const port = 3000` → any free port (e.g., `4000`).
  - Update URLs accordingly (e.g., `http://localhost:4000`).

- **Add new routes to the root app**
  - Edit the root `index.js` and add `app.get(...)` or other HTTP methods as needed.

- **Add new blog pages**
  - Create or update Handlebars templates under `EXPRESSBLOG/views/`.
  - Update `EXPRESSBLOG/routes/blog.js` if you introduce new endpoints.

## 9. Troubleshooting

- **Port already in use**
  - Symptom: `EADDRINUSE: address already in use :::3000`
  - Cause: Another app (possibly the other Express app) is already using port 3000.
  - Fix: Stop the other app, or change the `port` value in `index.js`.

- **Templates not rendering**
  - Ensure:
    - The view engine is set to `handlebars`.
    - Templates are under `views/` with the correct names.
    - Layout file is `views/layouts/main.handlebars` and includes `{{{body}}}`.

- **Static files not loading**
  - Confirm the static directory path:
    - Root app: `public/` under the project root.
    - Blog app: `static/` under `EXPRESSBLOG/`.
  - Check that file URLs in the HTML/Handlebars match the filesystem paths.
